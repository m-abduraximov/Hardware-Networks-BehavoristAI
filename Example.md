## Introduction to AI — Starting Draft

**Artificial intelligence (AI)** is technology that enables computers to perform tasks that usually require human intelligence, such as recognizing patterns, understanding language, or making decisions.

**Machine learning (ML)** is a type of AI in which computers learn patterns from examples and data rather than following only explicitly written rules. Therefore, machine learning is part of AI, but not all AI uses machine learning.&#x20;

Example: Email spam filter

A spam filter uses machine learning to study examples of spam and legitimate emails. It learns patterns, such as suspicious links or misleading language, and predicts whether new emails are spam.

Possible mistake: The filter might incorrectly classify an important email from a university professor as spam. This shows that AI systems can make errors and should not always be trusted without checking.
