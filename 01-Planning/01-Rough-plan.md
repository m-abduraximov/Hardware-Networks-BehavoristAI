## Project Scope and Learning Goals
### Target Learners
First-year university students and high-school graduates who:
- have no previous knowledge of computer hardware, computer networks, or artificial intelligence.
- use computers and smartphones every day but do not understand how these devices work.
- have no programming experience or technical background.

### Learning Goals
After using our materials, a beginner should be able to:
- **Hardware:** name the main parts of a computer (CPU, memory, storage, input and output devices) and explain what each part does; explain how sensors and actuators let a robot sense and act in the physical world.
- **Networks:** explain what a network, an IP address, a packet and a protocol are; describe, step by step, how a message travels from one device to another using the layered TCP/IP model.
- **Behaviorist AI:** define behaviorist (behavior-based) AI as intelligence that comes from direct interaction with the environment; 
explain how it differs from AI that first builds an internal model of the world; 
connect reward-based learning with the idea of behaviorism.
- **Integration:** for a simple robot, point out which hardware senses, which network link carries the data and which behavior rule decides the action.
